## Running the Game
Clone the repository or download the ZIP file, then run `doppel.exe` located in the `bin` folder.

## Controls
| Key | Description |
|----|----|
|WASD| move|
| Shift | sprint|
| Space | jump| 
| E | pick up objects| 
| F| throw remote|
| LMB | use remote|
|ESC| toggle pause menu|
| N | toggle normal mapping|
| Q | toggle controls guide|
